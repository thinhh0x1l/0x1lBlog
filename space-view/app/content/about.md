# Về 0x1lBlog

Chào mừng bạn đến với **0x1lBlog** — nền tảng blog chia sẻ kiến thức lập trình và sáng tạo nội dung dành cho cộng đồng công nghệ.

## Tính năng chính

- **Viết blog với Markdown editor** — hỗ trợ syntax highlight, image upload, auto-save draft
- **Hệ thống reaction 6 loại** — Like, Love, Haha, Wow, Sad, Angry
- **Bình luận 2 cấp** với threading, tối đa reply 1 cấp
- **Follow tác giả** và xem feed cá nhân hóa
- **Series** — gom các bài viết liên quan thành bộ
- **Hệ thống cấp độ và reputation** — tích điểm qua hoạt động
- **Điểm danh hàng ngày** — duy trì streak nhận thưởng
- **Bookmark bài viết yêu thích** — đọc lại sau
- **Canvas cộng đồng** — vẽ chung trên khung vẽ digital

## Công nghệ

| Thành phần | Công nghệ |
|------------|-----------|
| Backend | Spring Boot 4.1 + Java 21 |
| Cơ sở dữ liệu | PostgreSQL 16 |
| Cache | Redis 8 (L2) + Caffeine (L1) |
| Object Storage | MinIO |
| Frontend | Vue 3 + Element Plus |
| Build | Vite |
